# 口袋软盘 · Pocket Floppy

口袋软盘是一个 iOS 上的视觉小说播放器：把你自己拥有的游戏包导入进来，写成一张张“软盘”，点开就玩。
Pocket Floppy is a visual-novel player for iOS: import game packages you own, and play them.

- 隐私政策 / Privacy policy: [PRIVACY.md](PRIVACY.md)
- 使用帮助与反馈 / Help and feedback: [SUPPORT.md](SUPPORT.md)
- 开源组件与源码 / Open-source components and source: [SOURCES.md](SOURCES.md)

口袋软盘不提供任何游戏下载，也不附带第三方游戏，不会破解加密或受保护的游戏。
Pocket Floppy offers no game downloads, ships no third-party games, and does not break encrypted or protected games.
